# 浏览与读图

[文档目录](README.md)

正式版有 RING（动态环）、LIVE（直播）、STATS（统计）、ARCHIVE（全文归档）四个视图。开发版额外提供采集状态和诊断信息。

## 离线浏览

离线查看：下载 [HANE-offline.zip](https://github.com/HANE-LAB/HANE/releases/download/offline/HANE-offline.zip)（网站每次发布时自动更新），解压后双击 `index.html`，不用安装任何东西。自己复制网站时，请带上整个 `site/`，保留 `media/` 和 `assets/` 的相对位置。字体与未归档的远程图片可能需要联网。

正式版将页面数据以 zlib + base64 编码嵌入 HTML，浏览器加载时解码。压缩不是加密，归档仍可从仓库的 `data/` 下载。线上不额外提供 `data.json`，本机仍生成 `site/data.json` 供测试和工具使用。

## 基本操作与时间

- 动态环默认播放，可暂停、调速、拖动拨轮或按月份跳转（播放中按「上个月 / 下个月」会平滑转过去，不会跳切）。选中轮盘后支持滚轮、方向键、Home/End 和空格；手机纵向滑动仍用于滚动页面。手机上动态环紧接在时间轴之后，首屏即可看到；月份按钮、光束说明放在环的下方。

- 播放中打开任何一条动态（信笺、光束、月份、绘马）时，轮盘停在原处；关闭后从同一处继续播放。鼠标在信笺或帳上移动、或用键盘在其中操作时也会先停住，免得要点的内容被翻走，离开后继续；手指按在上面也一样，抬起手指或开始滚动页面后继续。只有按「暂停」才会一直停着；暂停后打开、关闭动态也保持暂停。轮盘滚出屏幕或切到后台时暂停绘制，回来后从原处继续。

- LIVE 或 STATS 里切换日本时间 / 北京时间后，动态环的月份归属、鸟居下的动态列表和全文页的时间一起换算，播放头仍停在切换前的那条动态上。

## 鸟居、注连绳、御守与绘马

- 动态环是一圈朱红鸟居，像千本鸟居那样排成环。每座鸟居是一个月：鸟居脚下列着那个月的动态，门洞里的点阵按日期和每四小时一格标出发帖时刻，匾上的朱印是当月条数。发得越多，那个月和它的鸟居就越宽。播放头所在的那座鸟居会亮起来。

- 鸟居有三种，看那个月的动态受欢迎的程度：把每个月动态的综合互动分取中位数，在所有月份里排名，前 15% 的鸟居门顶插着一对火羽（羽根朱红、羽尖淡金，播放头所在时会发亮），后 35% 是不上漆、笠木平直的素木鸟居，其余是朱漆鸟居；没有动态的月份是素木。千本鸟居本来就是信众供奉的，所以门的样子跟着大家的支持走。

- 鸟居内侧的注连绳由她每天的开播预告（标为「直播预告」的动态，例如「今天也马上开播！」）编成：发了预告的那天，绳子是完整的稻草色，没发就缺一截。

- 御守一般一年一换，所以每年开头挂一枚写着「皆勤」的御守，旁边写着年份和「发预告的天数/这一年的天数」，例如 2024 年是 359/366 天。第一年从首条动态算起，今年算到最新一条。悬停或点击都会显示说明，点击还会转到那一年。

- 绘马是参拜的人写下心愿挂在神社里的木牌，这里对应粉丝写下的评论：那个月的动态收到的评论越多，绳下挂的绘马越多（按评论最多的那个月开平方换算，最多 15 块，挤不下时分三排错开）。悬停看那个月的评论总数，点开是那个月评论最多的一条。

- 手机上，图例显示在转盘下方。

## 光束、信笺与直播「帳」

- 一束光对应一条动态。长度按所选累计互动指标统一缩放；综合分为 `点赞 + 3×评论 + 5×转发`，也可选择单项。金光代表所选指标前 10%，燃羽代表前 3%。签按综合互动分分档，具体刻度见页面读图说明。光束周围的火星只是装饰：互动越高的光束冒得越多，颜色从暖橙色开始，比光束暗；画面里最亮的白和金只留给金光、燃羽和当前动态。

- 内圈信笺随当前动态翻页，点击查看原文；红线指向对应光束。

- 人物下方（手机上在信笺下方）的「帳」写着播放头那个月和那一晚的直播档案：本月直播几场、共几小时，当晚几点开播、是连播第几天，以及自首条动态起的第几天。一晚算到次日 6:00，过了零点才开的场也归当晚。这里只读直播档案、不拿动态里的开播卡片充数；档案缺失的月份会写「本月没有直播档案」或档案从何时开始。点它会跳到「直播」页的同一个月。

## 烟、羽毛与布局

- 内圈飘着线香烟和白羽（初版的效果）。烟从当前可见的动态升起，互动越高的动态冒烟越多、越亮。平时滑过的白羽有多少，跟着播放头那个月的直播总时长走，只读直播档案（按全档最长的那个月、用平方根刻度换算），没有直播档案的月份只有烟。燃羽或有签的动态经过播放头时，会飞起一束亮羽。

- 红金结饰是装饰，人物保持原有静态表情。桌面放大，人物、帳和信笺在首屏可见的那部分轮盘里居中；手机竖屏时人物与信笺并排、帳在下面，不挡住指向当前动态的红线。系统“减少动态”会停止结饰摇摆并把翻页改为淡入，火星和播放照常。暂停时仍可手动切换信笺。

## Kobuta 小猪

- **Kobuta 小猪**使用火羽直播切片里戴绿领巾的立体小猪跑步循环，像网页宠物一样常驻页面、一直在跑，没有开关。素材是一个完整步态周期（22 帧），首尾无缝衔接；帧按跑过的距离推进，脚步不会打滑。默认在右下角沿一条斜视角的小椭圆跑道一圈圈跑（近处向左，远处向右并略小），转弯时像纸片一样翻身。

- 用鼠标或手指可以把小猪拎到页面任何地方：拎起时蹬腿冒汗，松手原地落下，甩出去会飞一段、碰到屏幕边反弹再落地；新位置保存在本机，下次打开仍在那里。点一下会冒爱心，并像火羽下播时那样喊「火羽こぶたこぶたこぶたこぶた」：先喊「火羽」，再按节拍一拍一个「こぶた」，每拍小跳一下、冒一个音符，整句像卡拉 OK 一样逐词点亮；气泡太长时会自动挪进屏幕。连点三下或偶尔会撒欢冲刺；动态环翻到「大吉」、或播放到最新一条（今，相当于下播）时它也会喊一遍（25 秒内最多一次）。拎起来时会叫「こぶっ!?」。键盘选中小猪后，方向键挪位置、回车摸摸。特效只用扬尘、爱心、汗滴、星星、音符和速度线，刻意不用动态环的火星与金光。

- 小猪只占自身大小、不占页面版面，位于详情抽屉之下；切到后台时停止，暂停轮盘不影响它。系统“减少动态”时照常奔跑，口号照常逐拍点亮，但不生成粒子和音符、不跳跃、不挤压。现代浏览器加载约 80 KB 的本地透明逐帧素材，旧浏览器使用 PNG 兼容版本；无视频、音频或 3D 引擎；素材来源和处理说明见 [资源来源](../hinome/assets/PROVENANCE.txt)。

## 渲染与兼容

- 渲染优先使用 WebGL2 / Worker，无法使用时回退 Canvas。支持自动、画质优先、流畅优先和兼容模式，不依赖专用服务器设置。
