## 如何维护文档

- `README.md` 保持项目入口，只放简介、最短使用路径与导航。
- 每项说明以表格中的专题为准；其他文档链接过去，不再复制长段正文。
- 用户操作写到使用文档，代码结构与测试写到开发指南，资源来源继续记录在 [PROVENANCE.txt](../hinome/assets/PROVENANCE.txt)。
- 功能变化时更新对应专题；只有简介、快速入口或导航变化时才修改首页。
- `docs/` 随源码公开，只写可公开的产品与开发信息。目录变化时同步修正文档间的相对链接。
- 动态条数、直播场次等持续变化的数据以页面和归档为准；需要保留历史统计时注明核对日期。
