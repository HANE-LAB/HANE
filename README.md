# HANE · 千本鸟居三部曲

火羽ひのめ的非官方档案三部曲的入口页：<https://hane-lab.github.io/HANE/>

- 第一部 [HANE Lantern · 灯下千本鸟居](https://hane-lab.github.io/HANE-LANTERN/)：她在 B 站发的每一条动态，一个月一座鸟居。
- 第二部 [HANE Voyage · 海上千本鸟居](https://hane-lab.github.io/HANE-VOYAGE/)：大航海名单上的每一个人是一艘船。
- 第三部 [HANE Flight · 云中千本鸟居](https://hane-lab.github.io/HANE-FLIGHT/)：她播过的每一夜是云中的一座鸟居。

首屏轮流播放三部作品自己渲染的镜头，往下滚是介绍和三部作品的选择页。版式和动效移植自 [Nova](https://github.com/sanidhyy/game-website)（MIT，见 `THIRD_PARTY_NOTICES.md`），用原生 JavaScript 重写。

页面是 `index.html` 和 `hub.js`，没有构建步骤，用浏览器直接打开就能看。字体从 Google Fonts 加载，没有网络时用系统字体。`video/` 和 `img/` 里的画面都取自三部作品。

非官方粉丝作品。数据来自 B 站公开信息，人物形象的版权归原作者。
