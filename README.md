# HANE

[在线浏览](https://hane-lab.github.io/HANE/) · [GitHub 仓库](https://github.com/HANE-LAB/HANE) · [离线版下载](https://github.com/HANE-LAB/HANE/releases/download/offline/HANE-offline.zip)

火羽ひのめ的非官方动态与直播档案。保存 B 站 UID `2094031249` 的动态原文、图片、译文和历史快照，生成可本地浏览或部署到 GitHub Pages 的静态网站。

采用**本地手动采集、GitHub 自动发布**。网页不需要后端；GitHub Actions 只检查并发布已经提交的数据，不定时抓取、不使用登录凭证。

## 启动与更新

在项目目录打开 PowerShell：

```powershell
# 查看已有正式版，不联网
.\.venv\Scripts\python.exe lab.py open

# 更新本地：动态、直播、图片、翻译和页面
.\.venv\Scripts\python.exe lab.py update

# 更新后上传归档到当前仓库，触发 GitHub Pages 发布
.\.venv\Scripts\python.exe lab.py publish

# 只用已有数据和译文缓存重建，不抓取、不翻译
.\.venv\Scripts\python.exe lab.py process --backend none --no-open
```

Windows 可双击 `run_windows.bat` 更新，Mac/Linux 使用 `bash run_mac.command`。换电脑推荐 Python 3.12，安装 `requirements.txt`；不要复制另一台电脑的 `.venv/`。启动脚本会自动准备虚拟环境。

| 版本 | 生成位置 | 内容 |
|---|---|---|
| 正式版（默认） | `site/` | 动态环、直播、统计、全文与内容详情 |
| 开发版 | `site-dev/` | 正式版内容及抓取状态、数据链、版本记录、素材来源 |

生成并打开开发版：

```powershell
.\.venv\Scripts\python.exe lab.py process --backend none --edition dev
```

`open --edition dev` 可再次打开开发版。两版互不覆盖，GitHub 只发布 `site/`。

离线查看：下载 [HANE-offline.zip](https://github.com/HANE-LAB/HANE/releases/download/offline/HANE-offline.zip)（网站每次发布时自动更新），解压后双击 `index.html`，不用安装任何东西。自己复制网站时，请带上整个 `site/`，保留 `media/` 和 `assets/` 的相对位置。字体与未归档的远程图片可能需要联网。

正式版页面里的数据经过压缩编码（zlib + base64），源码里没有能直接读的文字，线上也不放 `data.json`。这只是不让人直接从 HTML 读数据，不是加密：归档本身就在仓库的 `data/` 里。本机仍会生成 `site/data.json`，供测试和工具使用。

## 浏览与读图

- 动态环默认播放，可暂停、调速、拖动拨轮或按月份跳转（播放中按「上个月 / 下个月」会平滑转过去，不会跳切）。选中轮盘后支持滚轮、方向键、Home/End 和空格；手机纵向滑动仍用于滚动页面。手机上动态环紧接在时间轴之后，首屏即可看到；月份按钮、光束说明放在环的下方。
- 动态环是一圈朱红鸟居，像千本鸟居那样排成环。每座鸟居是一个月：鸟居脚下列着那个月的动态，门洞里的点阵按日期和每四小时一格标出发帖时刻，匾上的朱印是当月条数。发得越多，那个月和它的鸟居就越宽。播放头所在的那座鸟居会亮起来。
- 鸟居有三种，看那个月的动态受欢迎的程度：把每个月动态的综合互动分取中位数，在所有月份里排名，前 15% 的鸟居门顶插着一对火羽（羽根朱红、羽尖淡金，播放头所在时会发亮），后 35% 是不上漆、笠木平直的素木鸟居，其余是朱漆鸟居；没有动态的月份是素木。千本鸟居本来就是信众供奉的，所以门的样子跟着大家的支持走。以现在的数据，2022 年 2 月到 11 月插着火羽，2023 年底到 2025 年大多是素木，2026 年 10 月又插上火羽。
- 鸟居内侧的注连绳由她每天的开播预告（标为「直播预告」的动态，例如「今天也马上开播！」）编成：发了预告的那天，绳子是完整的稻草色，没发就缺一截。
- 御守一般一年一换，所以每年开头挂一枚写着「皆勤」的御守，旁边写着年份和「发预告的天数/这一年的天数」，例如 2024 年是 359/366 天。第一年从首条动态算起，今年算到最新一条。悬停或点击都会显示说明，点击还会转到那一年。
- 绘马是参拜的人写下心愿挂在神社里的木牌，这里对应粉丝写下的评论：那个月的动态收到的评论越多，绳下挂的绘马越多（按评论最多的那个月开平方换算，最多 15 块，挤不下时分三排错开）。安静的 2024、2025 年每月只有一块，2022 年每月四到九块，2026 年 10 月挂满。悬停看那个月的评论总数，点开是那个月评论最多的一条。
- 手机上，图例显示在转盘下方。
- 一束光对应一条动态。长度按所选累计互动指标统一缩放；综合分为 `点赞 + 3×评论 + 5×转发`，也可选择单项。金光代表所选指标前 10%，燃羽代表前 3%。签按综合互动分分档，具体刻度见页面读图说明。光束周围的火星只是装饰：互动越高的光束冒得越多，颜色从暖橙色开始，比光束暗；画面里最亮的白和金只留给金光、燃羽和当前动态。
- 内圈信笺随当前动态翻页，点击查看原文；红线指向对应光束。内圈不画动态之间的关系连线：统计过，几乎所有连线都只是「自动分类相同」（大多是相邻几天的开播预告），说明不了什么。
- 人物下方（手机上在信笺下方）的「帳」写着播放头那个月和那一晚的直播档案：本月直播几场、共几小时，当晚几点开播、是连播第几天，以及自首条动态起的第几天。一晚算到次日 6:00，过了零点才开的场也归当晚。这里只读直播档案、不拿动态里的开播卡片充数；档案缺失的月份会写「本月没有直播档案」或档案从何时开始。点它会跳到「直播」页的同一个月。原先内圈那排 @ 过的人名（铃）已经去掉。
- 内圈飘着线香烟和白羽（初版的效果）。烟从当前可见的动态升起，互动越高的动态冒烟越多、越亮。平时滑过的白羽有多少，跟着播放头那个月的直播总时长走，只读直播档案（按全档最长的那个月、用平方根刻度换算），没有直播档案的月份只有烟。燃羽或有签的动态经过播放头时，会飞起一束亮羽。
- 红金结饰是装饰，人物保持原有静态表情。桌面放大，人物、帳和信笺在首屏可见的那部分轮盘里居中；手机竖屏时人物与信笺并排、帳在下面，不挡住红线和关系编号。系统“减少动态”会停止结饰摇摆并把翻页改为淡入，火星和播放照常。暂停时仍可手动切换信笺。
- 播放中打开任何一条动态（信笺、光束、月份、绘马）时，轮盘停在原处；关闭后从同一处继续播放。鼠标在信笺或帳上移动、或用键盘在其中操作时也会先停住，免得要点的内容被翻走，离开后继续；手指按在上面也一样，抬起手指或开始滚动页面后继续。只有按「暂停」才会一直停着；暂停后打开、关闭动态也保持暂停。轮盘滚出屏幕或切到后台时暂停绘制，回来后从原处继续。
- LIVE 或 STATS 里切换日本时间 / 北京时间后，动态环的月份归属、鸟居下的动态列表和全文页的时间一起换算，播放头仍停在切换前的那条动态上。
- **Kobuta 小猪**使用火羽直播切片里戴绿领巾的立体小猪跑步循环，像网页宠物一样常驻页面、一直在跑，没有开关。素材是一个完整步态周期（22 帧），首尾无缝衔接；帧按跑过的距离推进，脚步不会打滑。默认在右下角沿一条斜视角的小椭圆跑道一圈圈跑（近处向左，远处向右并略小），转弯时像纸片一样翻身。
- 用鼠标或手指可以把小猪拎到页面任何地方：拎起时蹬腿冒汗，松手原地落下，甩出去会飞一段、碰到屏幕边反弹再落地；新位置保存在本机，下次打开仍在那里。点一下会冒爱心，并像火羽下播时那样喊「火羽こぶたこぶたこぶたこぶた」：先喊「火羽」，再按节拍一拍一个「こぶた」，每拍小跳一下、冒一个音符，整句像卡拉 OK 一样逐词点亮；气泡太长时会自动挪进屏幕。连点三下或偶尔会撒欢冲刺；动态环翻到「大吉」、或播放到最新一条（今，相当于下播）时它也会喊一遍（25 秒内最多一次）。拎起来时会叫「こぶっ!?」。键盘选中小猪后，方向键挪位置、回车摸摸。特效只用扬尘、爱心、汗滴、星星、音符和速度线，刻意不用动态环的火星与金光。
- 小猪只占自身大小、不占页面版面，位于详情抽屉之下；切到后台时停止，暂停轮盘不影响它。系统“减少动态”时照常奔跑，口号照常逐拍点亮，但不生成粒子和音符、不跳跃、不挤压。现代浏览器加载约 80 KB 的本地透明逐帧素材，旧浏览器使用 PNG 兼容版本；无视频、音频或 3D 引擎；素材来源和处理说明见 `hinome/assets/PROVENANCE.txt`。
- 渲染优先使用 WebGL2 / Worker，无法使用时回退 Canvas。支持自动、画质优先、流畅优先和兼容模式，不依赖专用服务器设置。

## 录制模式（做视频用）

在网址后面加 `?film`，页面只剩动态环：转盘铺满整个窗口，标题、按钮、时间轴、说明和鼠标指针都隐藏。人物、帳、信笺、签和小猪照常显示。录制模式固定用「画质优先」，不会在录到一半时自动降级。

网址参数可以设定开场画面，参数之间用 `&` 连接：

| 参数 | 作用 |
|---|---|
| `at=2022-10-12` | 从这一天的第一条动态开始；也可以写到分钟，例如 `at=2022-10-12T22:00`。时间按页面当前的时区（默认日本时间）。 |
| `speed=2` | 播放速度，可以是 0.5、1、2、4 等，最大 16。 |
| `paused` | 打开时先暂停。 |
| `key` | 保留右下角的图例。 |
| `pig=0` | 不显示小猪。 |
| `quality=auto` | 改回自动画质（默认是画质优先）。 |

例如，本地打开 `http://127.0.0.1:8765/?film&at=2022-10-12&paused` 会停在 2022 年 10 月 12 日。线上网址后面加同样的参数也可以。

录制脚本（例如 Playwright）可以用页面上的 `window.HANE` 控制镜头：

- `HANE.seek("2022-10-12", 1500)`：播放中用 1.5 秒转过去，暂停时直接跳过去；返回那条动态的时间。
- `HANE.latest(1400)`：转到最新一条。
- `HANE.play()`、`HANE.pause()`、`HANE.speed(0.5)`：播放、暂停、调速。
- `HANE.now()`：当前播放头那条动态的时间。

录制建议：

1. 把浏览器窗口设成 1920×1080，按 F11 全屏，用 OBS 录 60 帧。
2. 如果后期要推近或裁切，用 Playwright 以 1920×1080 的视口、`deviceScaleFactor: 2` 截图或录制，转盘会按 4K 分辨率绘制。
3. 每个镜头单独录一段，开头用 `at` 和 `paused` 定好位置，再用 `HANE.play()` 开始，剪辑时好对齐旁白。

## 采集与历史保存

游客模式可能只返回部分内容。需要登录态时，将 `config.local.example.toml` 复制为 `config.local.toml`：

1. 在 Chrome / Edge 登录 B 站，按 F12 打开 **Application（应用程序）**。
2. 在 **Storage → Cookies → B 站网址** 找到 `SESSDATA`，复制其 Value。
3. 填入本地配置的 `[bilibili] sessdata`；可选填入同一浏览器的 `buvid3`。

登录凭证只留本机，不能放在 `config.toml`、公开仓库、截图或聊天中。Cookie 失效后重新填写；遇到风控应稍后重试，不要提高请求频率。

采集逐页落盘，中断后普通 `update` 会续传。完整遍历后，每次更新刷新近期动态；距上次全量至少 7 天时重新核对历史。`update --full` 会从头核对；`fetch --max-pages N` 可限制本次页数。连续空页、风控和达到上限都不等于历史抓完，状态见开发版及 `data/state.json`。

内容编辑保留旧版，互动数和粉丝数按采集时间积累。连续两次完整遍历未出现的动态标记为不可见，原文和图片仍保留。已删除、隐藏或无权限的内容，以及首次采集之前的变化，无法补回。当前归档不包含评论正文、逐条弹幕、视频或直播原文件。

| 位置 | 保存内容 |
|---|---|
| `data/raw_items.json` | 最近取得的原始动态响应 |
| `data/snapshots/` | 不覆盖的动态内容版本 |
| `data/metrics/`、`data/history.jsonl` | 互动数与粉丝数观察记录 |
| `data/media/`、`data/media.json` | 图片、来源及下载状态 |
| `data/translations.json`、`data/llm_notes.json` | 按原文匹配的翻译和分析缓存 |
| `data/translation_review.json`、`data/translation_versions/` | 校订与旧译文版本 |
| `data/live_sessions.json`、`data/live_snapshots/` | 直播原始记录与修订版本 |
| `data/state.json`、`data/live_state.json` | 断点、完整性及同步状态 |
| `logs/runs.jsonl` | 本机运行诊断，不进入公开仓库 |

请独立备份**整个 `data/`**。`site/` 是生成物，不能替代原档。公开仓库中的档案可以下载，正式版与开发版的区别不构成访问权限隔离。

## 直播档案

来源为 [nailv 的火羽页面](https://stats.nailv.live/streamer/2094031249)使用的 Danmakus 公开接口，直播间 `22748536`，无需注册、Key 或 B 站 Cookie。`update` / `publish` 一起同步；`python lab.py live --no-open` 可单独更新。

截至 2026-10-15，已保存 **2,159 条动态、284 张图片、1,077 场直播**。直播来源缺少 2024 年记录，另有 58 场不完整；缺记录不能推断为停播。时间带的位置表示开始时刻，长度表示时长，跨午夜会分段。记录营收不是主播到手收入，最高高能人数不是同时在线人数；缺值与来源返回的零值分别展示。

来源异常时保留旧档，后续补录和修订会保存新版本。附近动态只提供时间线索，不自动认为属于同一场直播。

## 免费翻译

默认 **Hy-MT2 1.8B Q4**，免费、免注册、CPU 离线直译。首次模型约 1.13 GB，网页访问者不下载模型；翻译进程按需启动、完成后退出。

```powershell
.\.venv\Scripts\python.exe lab.py setup-translation
.\.venv\Scripts\python.exe lab.py process --backend hymt
```

本机模型已经准备好。自动安装支持 Windows / Linux x64；下载内容固定版本并校验 SHA-256，存放在 `.models/hy-mt/`，不提交仓库。许可与来源：[Hy-MT2](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF)、[llama.cpp](https://github.com/ggml-org/llama.cpp)。

原文始终保留，校订按原文指纹匹配，原文改变后旧校订失效。机器翻译仍可能误解省略主语和梗，不等同于专业人工审校。`auto` 按 HY-MT → Google 尝试，免费在线接口可能限流；其他后端只在明确选择时使用。`--backend none` 仅读取已有缓存。

## 开发与发布

[部署和恢复说明](docs/DEPLOY.md)。

```text
python -X utf8 dev/test_units.py
python -X utf8 dev/test_archive.py
python -X utf8 dev/test_translation.py
python -X utf8 dev/test_live.py
node dev/test_render.cjs
node dev/test_live.cjs
python dev/demo.py
```

测试使用虚构数据及 `dev/.sandbox/`。`shots.py` 用于视觉检查，它的输出可随时清理。有效测试保留，过程截图、探测响应和历史修复报告不进入发行目录。

代码按抓取、归档、规整、翻译、分析、构建分层，无数据库和常驻后端。退出码 `0` 表示完成，`1` 失败，`2` 部分完成或有警告，`130` 人工中断。页面生成成功不代表本次采集成功，请查看终端或开发版。
